# Crossheir

A simple Java app to create an overlay on your screen (mainly use for custom crosshair).

---

## Requirement

- Java 21 or above.

## Guide

- Clone the project.
- Install Java.
- Install Maven for Java.
- Open terminal, run maven build package.
- In the target folder, run the JAR file by double click or paste this in terminal: java -jar target/crosshair-app-1.0-SNAPSHOT.jar.
- Now the app should be open, it will be pretty easy to understand.
